# Pitline binaries

Public downloads for the Pitline client. **Source is not in this repository.** Product source lives in the private `pitlinehq/pitline` repo.

## Install

### Shell installer (macOS / Linux)

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/pitlinehq/releases/releases/latest/download/pitline-installer.sh | sh
pitline install-service
```

### Homebrew

```sh
brew install pitlinehq/tap/pitline
pitline install-service
```

The Homebrew formula is published to [pitlinehq/homebrew-tap](https://github.com/pitlinehq/homebrew-tap) and downloads the same prebuilt archives hosted here.

Docs: [pitline.dev/install.html](https://pitline.dev/install.html) (draft until the site PR merges).

## What ships on a version tag

- `pitline-installer.sh`
- `.tar.gz` archives for Linux (gnu/musl, x86_64 and arm64) and macOS (Intel and Apple Silicon)
- checksums / signatures as generated by cargo-dist

There are **no GitHub Releases here yet**. The first `v*` tag on the private product repo (mirrored here) will populate them.

## Notes

- The client is fully local: no analytics, telemetry, or other data collection by Pitline Inc.
- macOS Gatekeeper may block unsigned binaries until Pitline Inc.’s Apple Developer org is approved and builds are Developer ID–signed + notarized.
- Website analytics on pitline.dev are separate and are not in this software.
